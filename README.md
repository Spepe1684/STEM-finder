# STEM Scout

A self-contained front-end prototype for a STEM opportunity finder.

## Run it
1. Open `index.html` in a modern browser. No install or build step is needed.
2. Search, filter, save opportunities, and open official program sites.
3. To publish it, you can upload the folder to a static host such as GitHub Pages or Netlify.

## Important notes
- This is a prototype with a small curated sample of opportunities, not a live or exhaustive directory.
- Confirm current deadlines, costs, eligibility, and availability on each official website.
- Saved items use browser localStorage on the current device.
- Before submitting a competition entry, review the current rules, credit any assistance as required, and make sure you understand and can explain the code. Customize the project and be accurate about your own contribution.
